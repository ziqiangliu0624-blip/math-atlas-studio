# 0.1.2 开发记录

日期：2026-10-02。基线提交：`37e3218`。源码通过 Git 管理；安装包与检查截图保存在本地，不纳入源码提交。

## 完成功能

- 2D／3D 空白画布、曲线／曲面与图层列表提供对应右键菜单。
- 图层编辑、重命名、复制、排序、显隐、删除支持撤销／重做，并恢复合理的选中状态；历史记录修改移出 React 状态更新函数，避免开发模式重复执行。
- 右键单击打开菜单，3D 右键拖动继续平移；拖动回原点或丢失指针捕获后也不会误弹菜单，下一次右键仍可正常使用。
- 分屏命令和导出作用于目标画布，工具栏显示当前画布对应的控制项；点击或键盘聚焦画布会更新当前目标。
- 2D 复制画布坐标，3D 复制采样几何上的近似命中点；3D 空白处不提供虚构深度。过期图像的坐标复制与导出禁用。
- 菜单支持菜单键／Shift+F10、方向键、Home／End、Enter／空格与 Esc；关闭后恢复焦点，输入区域提供原生文本右键菜单。
- 菜单适配亮暗主题和窗口边缘；显卡连接中断时禁用相机与导出动作，仍可管理表达式并使用 2D。
- 更新版本号、README、设计说明书与开发计划。
