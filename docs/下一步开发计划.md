# Math Atlas Studio 下一步开发计划

日期：2026-10-02。基线：`main`，提交 `37e3218`，当前应用版本 `0.1.1`。

计划初稿用于确定开发范围；首阶段现已实现为 **0.1.2**。已确认并完成首版 **2D／3D 画布和图层列表** 右键菜单，复制、删除等修改操作同时支持撤销／重做。交付状态见 [0.1.2 开发记录](./0.1.2开发记录.md)。

## 1. 当前基础与本轮目标

项目已经实现 2D 显式函数、极坐标曲线、参数曲线，3D 高度曲面与空间曲线，以及示例、命名参数、亮暗主题、本地工程保存／恢复和 PNG 导出。0.1.1 基线已有撤销／重做、图层显隐与删除、画布命中选择；0.1.2 新增右键菜单、图层复制、重命名入口和排序。

沿用现有 Electron + React + Canvas 2D + Three.js 架构，保持学生和自学者使用本地数学绘图工具的产品定位。右键菜单的作用是缩短常用操作路径，视觉样式沿用现有亮暗主题。

**下一版本建议目标：0.1.2，完成右键菜单、必要的图层管理和交互回归验证。** 后续版本编号和范围在本阶段验收后确定。

## 2. 第一阶段：右键交互与图层操作（最高优先级）

### 2.1 按右键位置提供不同菜单

| 位置 | 首版菜单 | 操作规则 |
| --- | --- | --- |
| 2D 空白画布 | 添加二维表达式、适配内容、重置视图、放大／缩小、复制此处坐标、导出当前画布 PNG | 坐标是右键发生位置对应的数学坐标；视图与导出操作作用于这块画布 |
| 2D 曲线 | 编辑表达式、重命名、复制图层、隐藏、上移／下移、删除；复制此处坐标 | 先命中并选中对应图层，再展示菜单；坐标明确标为画布坐标，不宣称为曲线上的精确解 |
| 3D 空白画布 | 添加三维表达式、适配内容、重置视图、俯视／正视／侧视、透视／正交切换、导出当前画布 PNG | 空白处没有确定的三维深度，不提供虚构的 XYZ 坐标 |
| 3D 曲面／空间曲线 | 编辑表达式、重命名、复制图层、隐藏、上移／下移、删除；聚焦此处、复制命中点坐标 | 复用射线命中结果；坐标按当前采样几何的近似值展示 |
| 图层列表行 | 编辑表达式、重命名、复制、显示／隐藏、上移／下移、删除 | 对隐藏或无效图层仍提供编辑和管理入口；首尾图层的排序操作按边界禁用 |

首版采用简短分组菜单，不加入多级子菜单。删除使用明确文字和危险操作样式；不可用项给出禁用状态及原因。重命名使用现有侧栏或轻量输入框，编辑表达式直接打开属性面板并聚焦输入框。

### 2.2 明确鼠标与键盘规则

- **右键单击打开菜单，3D 右键拖动继续平移。** 在按下到松开期间记录位移，先以约 5 个 CSS 像素作为拖动阈值；拖动超过阈值后不弹菜单，也不误选对象。Windows 的菜单事件可能先于松开发生，需要结合完整指针状态判断。
- 保持 2D 原有左键／中键拖动平移、3D 左键旋转和滚轮缩放。拖动结束后，下一次正常右键单击应能立即打开菜单。
- 点击外部、按 Esc、切换工程／视图、窗口失焦时关闭菜单；菜单关闭后恢复合理的键盘焦点。
- 支持菜单键与 Shift+F10 打开菜单、方向键移动、Enter 执行。键盘从图层行打开时使用该行作为锚点，从画布打开时使用选中对象或画布中心，提示坐标来源。
- 菜单自动避让窗口边缘；高 DPI 下菜单位置、点击位置与数学坐标保持一致；打开菜单时不触发底层画布拖动或快捷键。
- 表达式和名称输入框保留文本编辑的剪切、复制、粘贴、全选能力；图形菜单只拦截对应画布和图层区域。

### 2.3 命令、撤销与持久化

- 菜单、工具栏和快捷键共享同一组操作，避免产生不同的行为。
- 每条画布命令带明确目标 `2d` 或 `3d`。现有适配、重置、新增和导出逻辑部分依赖全局模式，在分屏中默认作用于 2D，必须补充目标画布参数。
- 复用现有历史记录，让复制、删除、重命名、排序、显隐以及改变视图的操作可以撤销／重做。一次离散操作只记录一步；选择对象、开关菜单、复制到剪贴板和导出不产生工程修改历史。
- 复制图层生成新 ID，复制表达式、有限绘制域、样式与最后有效表达式；默认命名为“原名称 副本”，插入原图层之后并选中新图层。现有命名参数保持项目级共享，界面应说明复制后的参数仍联动。
- 删除后选中相邻图层，删除最后一个图层后正常进入空画布；撤销／重做时保持有效且合理的选中状态。
- 复用现有名称与数组顺序存储，保存重开后图层名称、顺序、显隐和相机状态一致；继续兼容 `schemaVersion: 1` 的工程文件。
- 对上一有效结果仍可执行编辑、隐藏、删除等管理动作；禁用基于过期图像的坐标探针与导出。按现有设计约束处理，并说明原因。
- 剪贴板写入通过 Electron 提供窄接口，浏览器预览使用可用的剪贴板接口；失败时给出反馈。成功提示包含复制内容，不把“已点击”视为复制成功。

### 2.4 实施顺序与涉及模块

1. 梳理 App 中的图层命令和画布目标，抽取最小的公共操作模块；保留既有保存、恢复和表达式逻辑。
2. 实现可复用菜单组件，完成定位、关闭、焦点与键盘操作，再接入图层列表作为第一条完整路径。
3. 在 Plot2D 中复用屏幕线段命中检测和坐标变换，接入曲线／空白处菜单。
4. 在 Plot3D 中接入射线命中、单击／拖动区分及聚焦命令，处理 OrbitControls 对菜单事件和右键拖动的接管。
5. 补齐分屏操作目标、剪贴板接口、持久化和历史记录验证，更新帮助与 README。

预计改动集中在 `src/App.jsx`、`src/components/Plot2D.jsx`、`src/components/Plot3D.jsx`、`src/styles.css`、`electron/main.cjs`、`electron/preload.cjs`；新增菜单组件和必要的交互／命令模块。按职责抽取，避免整库迁移或重写。

### 2.5 本阶段验收

- 在四类画布位置及图层行右键，菜单类型和对象目标正确；隐藏图层不会被画布命中，重叠图层按绘制顺序／距离使用稳定规则。
- 3D 右键拖动不弹菜单；单击、拖动、取消、失去指针捕获与窗口失焦后状态均正常。
- 分屏右侧的新增、适配、重置与导出作用于 3D，左侧作用于 2D。
- 连续复制、重命名、排序、隐藏、删除后逐步撤销／重做，图层内容、顺序和选择正确；工程保存重开后仍一致。
- 菜单关闭后不会执行旧工程或已删除图层的动作；无命中、无有效采样、错误表达式和 WebGL 不可用时有明确降级行为。
- 亮暗主题、最小窗口、窗口四角和 Windows 100%／150%／200% 缩放下菜单可读且不被裁切；仅用键盘也能操作。

## 3. 第二阶段：补齐绘图与导航的基础体验

第一阶段验收后，按以下顺序推进：

1. **精确视图范围**：输入 2D X／Y 范围、锁定等比例坐标、框选放大；明确 3D 绘制域、坐标盒范围和相机缩放分别控制什么。
2. **连续操作历史**：将一次拖动、连续滚轮缩放、滑块拖动和表达式编辑合并为合理的撤销步骤；处理输入框自身文本撤销与全局工程撤销的冲突。
3. **完整图层样式与锁定**：线宽、实／虚／点线、透明度与锁定。锁定前先定义属性编辑、排序、删除、命中选择和共享参数变化的规则，再加入工程格式的兼容默认值。
4. **导航与信息反馈**：活动画布指示、坐标读数、固定探针、视图前进／后退和菜单操作后的状态提示；过期结果不得参与探针读数。

验收以“比较多个函数 → 精确调整视图 → 修改参数 → 撤销 → 保存重开 → 导出”为完整流程。

## 4. 第三阶段：基础几何与学习闭环

- 增加 2D 点、线段、直线、向量和文本，采用明确的图层类型与统一命中接口。
- 支持几何对象平移、旋转、缩放、镜像，并与右键菜单、属性面板和撤销／重做共用操作路径。
- 增加直线斜率、向量与几何变换示例，保持表达式、参数和简短数学说明同步。
- 再完善导出尺寸、倍率和透明背景，并验证保存重开后的样式与视图一致性。
- 新对象类型需要工程格式迁移方案与旧工程回归；涉及更重采样前再引入后台计算与性能指标。

隐式曲线、不等式、参数／隐式曲面、CSV 数据图表和高级分析在基础交互稳定后分批推进，顺序参考原设计说明书。
