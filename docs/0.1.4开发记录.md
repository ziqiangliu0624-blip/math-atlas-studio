# 0.1.4 开发记录

日期：2026-10-02。基线：`d73f8f4`（已推送的 0.1.3）。本次完成第三阶段的二维基础几何与学习闭环。

## 已实现

- 独立的几何图层：点、线段、无限直线、向量、中文多行文字。渲染与命中共用几何数据，直线按视图裁切，向量包含箭头，文字按旋转／镜像后的范围命中。
- 画布放置与坐标直接创建两条入口；空白画布右键可原位添加点／文字。首次加入几何图层启用等比例坐标，可主动解除；数值坐标不受网格模式影响。
- 精确编辑锚点／端点、文字内容、字号和角度；直线两点重合、空值、非有限数值及超出安全界限的输入被拒绝。
- 拖动端点修改坐标，拖动对象整体平移。拖动采用局部预览，松开仅记录一步修改；Esc、指针取消、丢失捕获或失焦丢弃预览。保存、撤销和其他工程修改前取消未完成的几何预览。
- 数值平移、逆时针旋转、正倍数缩放、水平／垂直轴镜像；可指定变换中心或选原点、对象平均中心。右键镜像使用全局 X／Y 轴，拖动旋转和缩放围绕对象平均中心。文字镜像包含字形翻转，字号限制在 10–96 像素。
- 复用图层复制、重命名、排序、显隐、样式、锁定与撤销；复制后的几何独立且解锁。锁定禁止几何拖动和数值变换。
- 几何探针签名取对象几何数据，修改坐标／文字等使其失效；无关表达式参数不影响几何探针，撤销恢复后读数恢复。
- 斜率、向量首尾相接、旋转／镜像三组学习示例，默认等比例。示例对象彼此独立，未添加自动几何约束联动。
- 二维／三维 PNG 自定义尺寸、1–4×倍率和透明背景；保持当前画面比例并扩展范围，隐藏选中控制点，保留网格。分配前限制每边最多 8192 像素、总计最多 1600万像素；三维导出后恢复相机投影与绘制尺寸。

## 工程兼容

使用 `schemaVersion: 2`，图层 `type` 明确为 expression 或 geometry。可打开版本 1 工程并补齐默认字段；保存为版本 2，旧版应用不能读取新格式。工程校验移至独立模块，覆盖迁移、混合图层往返和重复标识拒绝；Electron 保存入口接受新版本。

本地恢复仍沿用原存储入口，以自动迁移既有草稿。撤销和视图导航仍限于当前打开的会话；文件保留对象、样式、锁定、当前视图与固定探针。
