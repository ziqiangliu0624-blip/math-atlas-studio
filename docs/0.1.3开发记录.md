## 已实现

- 2D 精确 X／Y 视图范围、等比例坐标、Shift 框选放大及右键框选模式；非法范围不改变工程。
- 3D 独立参考坐标盒，明确与图层绘制域和相机缩放的区别；坐标盒不裁切图形。
- 拖动、滚轮、滑块和连续表达式输入合并撤销；保存、撤销及离散命令前收齐待记录的三维相机状态。
- 曲线线宽、实／虚／点线、图层透明度；三维曲面支持颜色与透明度。空间曲线采用 Three.js 宽线组件，命中坐标取折线上的近似点。

- 每块画布一个固定探针；表达式、绘制域、项目参数变化、隐藏、完全透明、过期结果或三维显卡连接中断时禁用相关读数与复制。
- 当前画布指示、独立的二维／三维视图后退与前进、Alt+方向键和操作反馈。
- 新字段沿用 schemaVersion: 1 的可选扩展，旧工程自动补齐默认值。已更新 README、计划和设计说明，版本号为 0.1.3。
