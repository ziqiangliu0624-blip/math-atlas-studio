# 图形绘制实验室

面向学习者的 Windows 本地 2D／3D 数学绘图应用。当前版本是 **0.1.4 可运行原型**，已实现学习与绘图的主要路径，但尚未覆盖设计说明书中的全部 MVP 条目。

## 已实现

- 2D：显式函数 `y=f(x)`／`x=f(y)`、极坐标曲线、参数曲线；坐标网格、缩放、平移、适配内容。
- 2D 基础几何：点、线段、无限直线、向量、多行文字；画布放置与坐标直接创建，端点／整体拖动，数值和拖动变换。
- 3D：高度曲面 `z=f(x,y)` 和空间参数曲线；曲面可分别设置 X、Y 绘制范围；旋转、缩放、平移、透视／正交投影与预设视角。
- 安全数学表达式解析、公式旁的可展开说明、命名参数滑块、有限绘制域、多个图层与学习示例。
- Windows 本地工程保存／打开、自动恢复、PNG 自定义尺寸／1–4×倍率／透明背景导出、亮色／暗色界面。
- 精确 2D X／Y 视图范围、等比例坐标和框选放大；独立 3D 参考坐标盒、固定坐标探针、视图前进／后退。
- 线宽、实／虚／点线、透明度与图层锁定；拖动、滚轮、滑块和连续公式输入按操作合并撤销。
- 画布与图层右键菜单；图层复制、重命名、排序、显隐、删除及撤销／重做；分屏中的操作和 PNG 导出支持指定画布。

项目不要求账号或网络连接。工程文件采用 `.graphproj` 扩展名；MVP 中内容为版本化 JSON，后续加入数据导入时再扩展为带资源的工程包。

## 右键操作

- 在空白画布右键，可添加表达式、适配／重置视图和导出当前画布；3D 还提供预设视角与投影切换。
- 在曲线、曲面或图层行右键，可编辑表达式、重命名、复制、显示／隐藏、上移／下移和删除。复制后的同名参数仍为项目级共享。
- **3D 右键单击打开菜单，按住右键拖动平移；左键拖动旋转，滚轮缩放。** 拖动后松开不会弹出菜单。
- 分屏时，点击或键盘聚焦某块画布后，工具栏操作作用于该画布；右键菜单始终作用于右键发生的画布。
- 2D 可复制右键位置的画布坐标；3D 只复制采样几何上的近似命中点，空白处没有确定的 XYZ 坐标。上一有效结果的探针复制与导出会禁用。
- 聚焦图层行或画布后按菜单键／`Shift+F10` 打开菜单；`↑/↓`、`Home/End` 选择，`Enter` 执行，`Esc` 关闭并恢复焦点。图层行按 `Enter` 可直接编辑表达式。
- 表达式、工程名和图层名输入框保留文本右键菜单。`Ctrl+Z` 在输入框中撤销文字，离开输入框后撤销工程操作；工具栏撤销按钮始终操作工程。

## 范围、样式与导航

- 工具栏「视图设置」输入二维 X／Y 的最小值和最大值，再点击「应用范围」。等比例坐标保持 X／Y 一个单位等长，扩展一轴适配画布；窗口大小改变时继续保持等比例。
- 按住 `Shift` 在 2D 画布拖出矩形可框选放大，也可从右键菜单启用框选；`Esc` 退出。仅框选放大改变视图，图层绘制域不变。
- 3D「视图设置」控制参考坐标盒的网格与边框。图层属性中的绘制域决定采样区间；相机缩放决定观察距离。坐标盒不裁切图形。
- 曲线支持 1–12 像素线宽、实线／虚线／点线与 0–100% 透明度；三维曲面支持颜色和透明度。完全透明的图层不参与画布命中。
- 锁定禁止修改图层属性、重命名、排序和删除，也不能交换锁定图层与相邻图层；仍可选择、显隐、复制。副本默认解锁。**命名参数仍为项目级共享，锁定不冻结参数。**
- 一次拖动或滑块拖动记录一步撤销；滚轮、按键连续缩放与公式输入在 800 毫秒停顿内合并，离开输入框或执行其他修改即结束合并。三维相机在手势结束后记录稳定位置，保存和撤销前会收齐待记录的相机变化。
- 右键「固定此处坐标探针」保存一个画布位置；每块画布最多一个。2D 显示画布坐标，3D 显示采样几何上的近似点；空白 3D 不提供探针。表达式、绘制域或项目参数改变、图层隐藏或完全透明、上一有效结果及显卡中断时，关联探针失效并禁用复制，撤销恢复原图形后可恢复读数。
- 工具栏箭头或 `Alt+←/→` 只前进／后退当前画布的视图，保留表达式、参数与样式；独立维护 2D 范围和 3D 相机历史。导航列表只在本次打开的工程内保留，保存文件保留当前视图和固定探针。
- 0.1.4 工程使用 `schemaVersion: 2`，明确区分表达式与几何图层；可打开旧的版本 1 工程并补齐默认设置。保存后使用版本 2，旧版应用不能打开该新格式。

## 几何创建、编辑与导出

- 二维工具栏选择点或文字后单击放置；线段、直线和向量依次单击两个位置。完成后回到选择模式，`Esc` 取消。空白处右键可原位添加点／文字，或启用其他绘制工具。
- 「坐标创建」选择对象类型、输入起点／终点，点击创建或用键盘提交；也可选中对象后在右侧精确修改坐标。坐标输入在 Enter／离开输入框时应用，空值和退化直线会被拒绝。
- 拖动对象整体平移；拖动选中对象的圆形端点修改坐标。几何拖动采用临时预览，松开记录一步撤销；Esc、指针取消、丢失捕获和窗口失焦丢弃预览。空白处拖动仍平移视图，Shift 拖动仍框选放大。
- 首次创建几何图层自动启用等比例坐标，学习示例也启用等比例。可在视图设置中解除。内部坐标始终使用二维笛卡尔坐标，极坐标网格不改变对象坐标。
- 属性栏可输入平移量、逆时针旋转角度、正缩放倍数和变换中心；中心可选原点或对象平均中心。镜像沿通过中心的水平／垂直轴。右键镜像沿全局 X／Y 轴；拖动旋转、缩放围绕对象平均中心。
- 几何图层沿用复制、重命名、排序、显隐、样式、锁定、撤销和保存；点的线宽控制标记尺寸，文字用独立字号与角度。锁定阻止拖动和数值变换。文字字号以屏幕像素计，缩放变换限制在 10–96 像素。
- 斜率、向量相加和旋转／镜像示例用实际对象演示；对象彼此独立，未建立自动约束联动。几何探针只随对象几何变化失效，不受无关函数参数影响。
- 「导出设置」控制宽高、倍率和透明背景；扩展画面以保留当前范围，保留网格并隐藏选中控制点。每边不超过 8192 像素、总计不超过 1600万像素；三维导出后恢复原相机与画布尺寸。

## 运行与打包

要求 Node.js 20+。在项目目录中运行：

```powershell
npm install
npm run build
npm run desktop
```

生成 Windows 安装包：

```powershell
npm run dist:win
```

安装包输出到 `release/`。当前提供 Windows x64 安装包；0.1.4 构建与自动化交互检查在 Windows 10 22H2 上完成，Windows 10／11 的安装、中文输入法和跨显示器缩放仍需实机验收。当前构建尚未配置代码签名证书，首次安装可能出现 Windows SmartScreen 提示。构建依赖需要在开发阶段下载，应用安装后可离线使用。

## 验证

```powershell
npm test
npm run smoke
npm run smoke:interactions
npm run smoke:phase2
npm run smoke:geometry
```

`smoke` 会在 `artifacts/` 保存 2D、3D 和暗色主题的截图，并输出渲染器错误摘要。运行它需要 Windows 图形桌面权限。

`smoke:interactions` 在隐藏的 Electron 窗口中发送鼠标与键盘事件，验证菜单命中、右键拖动、图层历史、分屏目标、工程存储和主题状态；截图与结果保存在 `artifacts/interactions/`。文件对话框由测试接收器替代，保存／导出内容写入该目录，剪贴板内容在检查后恢复。自动化检查不能替代 Windows 10／11 安装和多显示器 DPI 的实机验收。

`smoke:phase2` 覆盖范围输入、等比例、框选、操作历史合并、样式与锁定、探针失效、双向视图导航和保存重开导出。使用真实鼠标／键盘，并核对三维实际绘制像素；产物保存在 `artifacts/phase2/`。

`smoke:geometry` 覆盖几何创建、数值编辑、拖动及取消、变换、复制锁定、探针、版本迁移和实际保存文件；核对二维／三维 PNG 的输出尺寸与透明像素，并检查学习示例、主题和小窗口。产物保存在 `artifacts/geometry/`。
