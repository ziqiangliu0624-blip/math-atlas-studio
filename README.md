# 图形绘制实验室

面向学习者的 Windows 本地 2D／3D 数学绘图应用。当前版本是 **0.1.1 可运行原型**，已实现学习与绘图的主要路径，但尚未覆盖设计说明书中的全部 MVP 条目。

## 已实现

- 2D：显式函数 `y=f(x)`／`x=f(y)`、极坐标曲线、参数曲线；坐标网格、缩放、平移、适配内容。
- 3D：高度曲面 `z=f(x,y)` 和空间参数曲线；曲面可分别设置 X、Y 绘制范围；旋转、缩放、平移、透视／正交投影与预设视角。
- 安全数学表达式解析、公式旁的可展开说明、命名参数滑块、有限绘制域、多个图层与学习示例。
- Windows 本地工程保存／打开、自动恢复、PNG 导出、亮色／暗色界面。

项目不要求账号或网络连接。工程文件采用 `.graphproj` 扩展名；MVP 中内容为版本化 JSON，后续加入数据导入时再扩展为带资源的工程包。

## 运行与打包

要求 Node.js 20+。在项目目录中运行：

```powershell
npm install
npm run build
npm run desktop
```

生成 Windows 安装包：

```powershell
npm run dist:win
```

安装包输出到 `release/`。当前提供 Windows x64 安装包；构建在 Windows 11 上完成，Windows 10 仍需实机安装和交互验证。当前构建尚未配置代码签名证书，首次安装可能出现 Windows SmartScreen 提示。构建依赖需要在开发阶段下载，应用安装后可离线使用。

## 验证

```powershell
npm test
npm run smoke
```

`smoke` 会在 `artifacts/` 保存 2D、3D 和暗色主题的截图，并输出渲染器错误摘要。运行它需要 Windows 图形桌面权限。
